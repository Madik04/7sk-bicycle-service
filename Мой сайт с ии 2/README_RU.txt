7SK Bicycle Service — сайт с AI-чатом и голосовым помощником

ЧТО ИЗМЕНИЛОСЬ
- В index.html добавлены две плавающие кнопки: ChatGPT и голосовой помощник.
- Отправка сообщения работает через POST /api/chat.
- Голосовой помощник сначала запрашивает разрешение на микрофон после нажатия кнопки.
- Добавлен Node.js сервер server.js.

ВАЖНО ПРО РАЗМЕЩЕНИЕ
Если загрузить ТОЛЬКО index.html на обычный статический хостинг, внешний вид и запрос разрешения микрофона будут работать, но ChatGPT не сможет отвечать: для этого нужен серверный endpoint /api/chat. Нельзя вставлять секретный OpenAI API-ключ в HTML/JavaScript — посетители смогут его украсть.

ЗАПУСК НА КОМПЬЮТЕРЕ (Windows)
1. Установи Node.js LTS.
2. Открой папку сайта в терминале.
3. Выполни: npm install
4. Скопируй .env.example в файл .env.
5. В .env укажи свой OpenAI API key в OPENAI_API_KEY.
6. Выполни: npm start
7. Открой http://localhost:3000

ДЛЯ ПУБЛИКАЦИИ
Нужен хостинг, который поддерживает Node.js (например, VPS или подходящая платформа для Node.js). Размести весь проект, задай OPENAI_API_KEY в переменных окружения хостинга и запусти npm start. Сам сайт должен открываться по HTTPS — это также необходимо для микрофона.

МИКРОФОН
В Chrome/Edge нажми «Включить микрофон» и выбери «Разрешить». Если ранее запретил доступ: значок слева от адреса сайта → Настройки сайта → Микрофон → Разрешить. На обычном HTTP-сайте микрофон может быть заблокирован; используй HTTPS или localhost.

ОСТАЛЬНЫЕ ФАЙЛЫ
Существующие страницы services.html, contacts.html, gpt.html, стили и скрипты сохранены.


НОВЫЕ ВОЗМОЖНОСТИ
- Добавлена верхняя стеклянная панель с анимированными вкладками и подсветкой текущего раздела.
- ChatGPT и голосовой помощник используют один общий диалог и контекст последних сообщений.
- История сохраняется локально в браузере; кнопка «Очистить» удаляет её.
- Голосовой режим может вести последовательный диалог: слушает вопрос, отправляет его AI, озвучивает ответ и снова слушает.
- Для поведения AI, похожего на ChatGPT, нужен действующий OpenAI API-ключ и доступный Node.js сервер. Это не тот же самый интерфейс/аккаунт ChatGPT, и расходы API оплачиваются отдельно.
