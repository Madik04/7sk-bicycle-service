7SK Bicycle Service — сайт (локальная копия)
Файлы:
- index.html       — главная
- services.html    — страница "Услуги и цены"
- contacts.html    — страница "Контакты"
- styles.css       — стили (тёмная тема)
- script.js        — скрипты (анимация, мобильное меню)
- README.txt       — этот файл

Как запустить (офлайн):
1) Скопируй все файлы в одну папку на компьютере.
2) Дважды кликни на file index.html — откроется в браузере.
   (Если браузер блокирует локальные скрипты — открой файл через Chrome/Edge/Firefox, обычно работает без проблем.)

Как упаковать в ZIP (Windows):
1) Выдели папку с файлами ➜ правый клик ➜ "Отправить" ➜ "Сжатая папка (zip)".
2) Переименуй архив, если нужно (например, 7sk_site.zip).

Как залить на хостинг (коротко):
- Можно загрузить все файлы в публичную папку на любом файловом хостинге (Netlify, Vercel, GitHub Pages и т.д.).
- Для GitHub Pages: создать репозиторий, добавить файлы, включить GitHub Pages (branch: main / gh-pages).
- Для Netlify: просто перетащи папку в панель Netlify — сайт будет доступен онлайн.

Редактирование контента:
- Текст редактируется в соответствующих .html файлах (открыть в любом текстовом редакторе).
- Стили — в styles.css.
- Скрипты — в script.js.

Если хочешь — могу:
- Собрать ZIP и скинуть ссылку.
- Или выгрузить сайт в репозиторий GitHub / Netlify (если дашь согласие и доступ / инструкции).

Удачи! Если нужно — переделаю цвета, шрифты или добавлю дополнительные сервисы.
